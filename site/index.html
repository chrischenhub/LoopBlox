01 / The research process

A loop for researching loops.

Edit a reusable controller, run development trials, let the evidence choose what to try next.

Search

Order, repetition, branches — ordinary Python. The episode fixes components, tools, model settings, and limits.

Evidence

Immutable source, paired task results, traces, and cost. Only scored candidates can be selected.

Holdout

Researchers close and selections freeze first. Final scores never feed back into search.
