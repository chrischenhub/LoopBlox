# Bundled fonts

- Departure Mono 1.500 — https://github.com/rektdeckard/departure-mono/releases/tag/v1.500
  Pixel Latin headings and navigation, also used by pi.dev. SIL OFL; see DepartureMono-LICENSE.
- JetBrains Mono — https://github.com/JetBrains/JetBrainsMono/tree/19371302b95d218af43299bce79ddbddd0bc364d
  Terminal chrome, component names and code, matching Omarchy's font family. SIL OFL;
  see JetBrainsMono-OFL.txt.
- Source Serif 4 (variable, upright + italic) — https://github.com/adobe-fonts/source-serif
  Running prose and headings, the role pi.dev gives Plantin MT Pro. SIL OFL; see
  SourceSerif4-OFL.txt.

All three font families are served locally under the SIL Open Font License. No remote font
requests are required.
